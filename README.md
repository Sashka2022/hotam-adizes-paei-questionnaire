# שאלון אדיג'ס – מיפוי סגנונות החלטה וניהול (PAEI)

אפליקציית רשת (סטטית, ללא צורך בבנייה) להעברת שאלון אדיג'ס למיפוי סגנונות החלטה וניהול. כוללת שאלון הדרגתי בעברית (RTL), אכיפת שיבוץ ניקוד ייחודי (8/4/2/1) עם הודעת טקסט צף, ודשבורד תוצאות עם גרף רדאר, תגיות בולטות סגנון, וייצוא ל-PDF/הדפסה. בנויה בערכת העיצוב של חותם.

## הרצה מקומית

```bash
python -m http.server 5173
```

ואז לפתוח `http://localhost:5173`.

## מבנה הפרויקט

- `index.html` – שלושת מסכי האפליקציה (פתיחה, שאלון, תוצאות)
- `css/` – עיצוב מבוסס Design System של חותם + עיצוב ייעודי
- `js/data.js` – 20 השאלות, טבלת הנורמות, ומפתח התוצאות המלא
- `js/app.js` – לוגיקת השאלון, החישוב, הגרף, וייצוא PDF/הדפסה
- `assets/logo/` – לוגו חותם
